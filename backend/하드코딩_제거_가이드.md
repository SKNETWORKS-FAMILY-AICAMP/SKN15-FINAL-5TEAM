**적용 방법:**

AUTO_SAVE = os.getenv("AUTO_SAVE", "false").lower() == "true"

### 2. 명령줄 인자 지원
```bash

python play.py --scenario cutscene5_akaza_encounter

# 디버그 모드
python play.py --debug

# 설정 파일 경로 지정
python play.py --config custom_config.json
```

**구현:**
```python
import argparse

def parse_arguments():
    parser = argparse.ArgumentParser(description='KIME Chat Agent')
    parser.add_argument('--scenario', type=str, help='시나리오 ID')
    parser.add_argument('--config', type=str, default='config.json')
    parser.add_argument('--debug', action='store_true')
    return parser.parse_args()

def main():
    args = parse_arguments()
    config = load_config(args.config)

    if args.scenario:
        scenario_id = args.scenario
    else:
        scenario_id = select_scenario(config)
```

## 📝 실습: 하드코딩 제거하기

### 예제 1: 친밀도 바 길이 설정
**기존 (하드코딩):**
```python
# play.py
bar = "█" * (score // 100) + "░" * (10 - score // 100)
```

**개선 (설정 파일):**
```python
# config.json
{
  "display": {
    "affinity_bar_length": 10,
    "affinity_bar_filled": "█",
    "affinity_bar_empty": "░"
  }
}

# play.py
def print_scenario_status(state: GraphState, config: dict):
    display_cfg = config.get("display", {})
    bar_len = display_cfg.get("affinity_bar_length", 10)
    filled = display_cfg.get("affinity_bar_filled", "█")
    empty = display_cfg.get("affinity_bar_empty", "░")

    bar = filled * (score // (1000 // bar_len)) + empty * (bar_len - score // (1000 // bar_len))
```

### 예제 2: 시나리오 경로 설정
**기존:**
```python
scenario_data = scenario_loader.load_scenario(f"{scenario_id}.json")
# 내부적으로 "data/scenarios/" 경로가 하드코딩됨
```

**개선:**
```json
// config.json
{
  "paths": {
    "scenarios": "data/scenarios/",
    "saves": "saves/",
    "assets": "assets/"
  }
}
```

```python
# play.py
def load_scenario(scenario_id: str, config: dict):
    paths = config.get("paths", {})
    scenario_dir = paths.get("scenarios", "data/scenarios/")
    full_path = os.path.join(scenario_dir, f"{scenario_id}.json")
    return scenario_loader.load_scenario(full_path)
```
