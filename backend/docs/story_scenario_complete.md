flowchart TD

D --> F[성공: 턴 내 달성 → 히든 엔딩]


## 핵심 특징

1. **빠른 죽음 분기**  
   - “스승님은 내가 지킨다!” 선택 시 즉시 bad ending

2. **탄지로 힌트**  
   - 위치: “야생적 냄새(이노스케)↔번개냄새(젠이츠)”  
   - 공략: “이노스케는 지는 걸 싫어해요”, “젠이츠는 네즈코를 지켜야”

3. **필수 순서**  
   - 이노스케 → 젠이츠 순서 준수해야 hidden ending

4. **이중 턴제**  
   - 전체 5턴, 개별 3턴

5. **캐릭터 성격 공략**  
   - 이노스케: 도발 효과  
   - 젠이츠: 네즈코 언급 효과

6. **위기 묘사**  
   - 턴 소모 시마다 “상황 악화” 삽입
