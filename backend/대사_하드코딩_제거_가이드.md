# 🎭 대사 하드코딩 제거 가이드

## 📋 현재 문제점

### ❌ 문제: 시나리오 JSON에 대사가 모두 하드코딩됨

```json
// cutscene5_simple.json (현재)
{
  "intro": {
    "dialogues": [
      {
        "turn": 0,
        "speakers": ["system", "tanjiro"],
        "contents": [
          "💨 열차의 충격으로...",  // ❌ 하드코딩된 대사
          "{{user}}!! 😰 괜찮아?!"   // ❌ 하드코딩된 대사
        ]
      }
    ]
  }
}
```

**문제점:**
1. LLM이 있어도 하드코딩된 대사만 출력됨
2. 캐릭터가 유연하게 반응하지 못함
3. 같은 상황에서 항상 똑같은 대사
4. Parent가 상황 판단, Children이 연기하는 구조가 작동 안 함

---

## ✅ 해결 방안: 대사 → 상황 설명으로 변경

### 🎯 핵심 아이디어

**기존 (하드코딩):**
```
JSON에 대사 저장 → Parent가 읽기 → Children이 그대로 출력
```

**개선 (LLM 활용):**
```
JSON에 상황 설명 저장 → Parent가 분석 → Children이 LLM으로 대사 생성
```

**변경 사항:**
- `dialogues` → `situations`
- `contents` (하드코딩 대사) 제거
- `scene_description` 추가 (상황 설명)
- `characters` 배열에 각 캐릭터의 역할, 감정, 동기 명시

### 2단계: Parent Agent 수정

Parent는 상황을 분석하고, Children에게 **"무엇을 말해야 할지"** 전달합니다.

#### 수정할 파일: `src/agents/parent_agent.py`

```python
def _process_cutscene(self, state):
    # JSON에서 대사를 직접 가져옴
    dialogues = stage_data.get("dialogues", [])
    for dialogue in dialogues:
        contents = dialogue.get("contents", [])  # 하드코딩된 대사
        # ...

# 개선 (✅)
def _process_cutscene(self, state):
    # JSON에서 상황 설명을 가져옴
    situations = stage_data.get("situations", [])

    for situation in situations:
        scene_desc = situation.get("scene_description", "")
        characters = situation.get("characters", [])

        # 각 캐릭터에게 전달할 상황 컨텍스트 생성
        dialogue_context = []
        for char_info in characters:
            dialogue_context.append({
                "speaker": char_info.get("id"),
                "situation": scene_desc,  # 상황 설명
                "role": char_info.get("role"),
                "emotion": char_info.get("emotion"),
                "motivation": char_info.get("motivation"),
                "context": char_info.get("context"),
                "order": char_info.get("order", 0)
            })

        # Children Agent에게 전달
        state.parent_decisions.dialogue_context = dialogue_context
```

## 🎯 변환 도구 제공

자동으로 기존 JSON을 새 형식으로 변환하는 스크립트:

```python
# convert_to_situations.py
import json

def convert_dialogue_to_situation(dialogue_data):
    """
    기존 dialogue 형식을 situation 형식으로 변환
    """
    speakers = dialogue_data.get("speakers", [])
    contents = dialogue_data.get("contents", [])
    emotions = dialogue_data.get("emotions", [])

    # 모든 대사를 하나의 장면 설명으로 통합
    scene_desc = "다음 상황이 벌어진다: " + " ".join(contents)

    characters = []
    for idx, speaker in enumerate(speakers):
        characters.append({
            "id": speaker,
            "order": idx,
            "emotion": emotions[idx] if idx < len(emotions) else "neutral",
            "role": f"{speaker}의 역할",  # TODO: 수동으로 채워야 함
            "motivation": contents[idx] if idx < len(contents) else "",
            "context": "상황 컨텍스트"  # TODO: 수동으로 채워야 함
        })

    return {
        "turn": dialogue_data.get("turn", 0),
        "scene_description": scene_desc,
        "characters": characters,
        "user_prompt": dialogue_data.get("user_prompt", "")
    }

def convert_scenario(input_file, output_file):
    with open(input_file, 'r', encoding='utf-8') as f:
        data = json.load(f)

    stages = data.get("stages", {})

    for stage_name, stage_data in stages.items():
        if "dialogues" in stage_data:
            situations = [
                convert_dialogue_to_situation(d)
                for d in stage_data["dialogues"]
            ]
            stage_data["situations"] = situations
            del stage_data["dialogues"]  # 기존 제거

    with open(output_file, 'w', encoding='utf-8') as f:
        json.dump(data, f, ensure_ascii=False, indent=2)

    print(f"✅ 변환 완료: {output_file}")
    print("⚠️ role과 context는 수동으로 채워야 합니다!")

# 사용법
convert_scenario("cutscene5_simple.json", "cutscene5_llm_driven.json")
```
